01

把 WPS 项目接入您的 Agent 🔌

四步完成，全程约三分钟。无需编写代码，也不需要安装任何插件。

1

在 WPS 项目中获取开发者令牌

打开 WPS 项目，进入左下角设置 → 开发者配置，页面中会显示一串以 rsq_ 开头的 API 令牌，点击右侧复制按钮即可。

2

打开配置页面，粘贴令牌

访问配置页 axhub.im/html/3dd5447e46d453c2，将令牌粘贴至输入框。
该页面仅在您的浏览器本地生成配置，不会上传，也不会保存。

3

点击「复制配置指令」

令牌填入后，右侧会自动生成一段配置指令，点击蓝色按钮复制。
这段内容是提供给 Agent 识别的，您无需理解其中的技术细节。

4

打开任意 Agent，粘贴并发送

打开您常用的 Agent，将复制的内容粘贴至对话框并发送。Agent 会自动完成配置并连接 WPS 项目，连接成功后会反馈已加载的能力数量。至此，接入完成 🎉

🔐 开发者令牌，请妥善保管

配置过程中，令牌仅写入您本机的 Agent 配置，不会上传至任何服务器。但该令牌等同于您的账号权限，请勿转发至群聊，也不要粘贴到共享文档中。

如令牌意外泄露，可在 WPS 项目「设置 → 开发者配置」中点击刷新按钮，原令牌即刻失效，重新配置一次即可。

⚠️ 若连接未成功，请先确认这一项

企业版账号需由管理员完成固定出口 IP 白名单配置后方可连接。如您已按上述四步操作但仍无法连接，请联系贵司 WPS 项目的企业管理员协助配置。

让结果更准确的三个建议 💡

首次使用时留意这三点，可以显著减少反复修改。

01

提到同事时，请使用通讯录中的姓名

Agent 依据贵司通讯录进行人员匹配。请使用实际姓名，如「张伟」；若表述为「商务部门的同事」，将无法准确定位。

如遇同名，可补充部门，例如 财务部的李娜。尚未确定人选时，也可先请 Agent 列出部门名单。

02

内容较多时，先让 Agent 出方案

在指令中加上 请先不要创建，Agent 会先把步骤、填写内容与负责人整理成清单供您确认。

在清单上调整，远比创建完成后再修改省事。

03

说明每一项要填什么类型

多说三个字，创建出的表单即可直接投入使用。

合同金额→数字签约日期→日期 合同正文→附件跟进人→选人 审批结论→单选验收清单→任务清单

其中金额类内容建议标注为数字类型——若存为文字，后续将无法参与统计分析。

拿不准时，也可以先让 Agent 给建议：

点击复制

我准备建一个合同审批流程，第一步需要填写：合同名称、客户全称、合同金额、折扣率、签约日期、付款方式、合同正文、签约负责人。 请根据每一项的实际用途，推荐合适的填写类型（文字、数字、日期、单选、多选、附件、选人等），并说明理由。其中后续需要统计分析的内容，请特别标注。

📌 两件事目前需要在界面上手动做

任务进度百分比——它是系统按子任务完成情况自动算的，改不了，也不需要改。任务标签——目前接口不支持，要打标签请在界面上点。其他您能在任务里看到的东西，Agent 基本都能改。

💡 一个好习惯：建和改尽量在同一次对话里完成

Agent 建完任务后，会记住每条任务的编号。换一个新对话，它就得重新找。所以一批任务的建立和后续调整，尽量放在同一个对话里做完，省事很多。

表格驱动派活：读表 → 按字段分派 → 建任务 → 评论通知

台账里标了「整改中」「待跟进」的行，让 Agent 直接变成任务派给对应的人，评论里把要求写清楚。

点击复制

读「施工进度台账」，把节点状态是「整改中」的行，每行建一条任务放到「施工进度看板」对应节点的卡片里。 责任人按施工班组对应：陈工班组→刘磊，王工班组→赵贵生，李工班组→刘希图，张工班组→袁小蛟。 任务描述带上合同编号、班组、现场说明，工期本周内，优先级较高。 建完在每条任务下评论 @ 责任人，说明台账里的整改要求。 最后回写台账，把这几行的「派工状态」改成「已派工」。

  • 4 行整改记录 → 4 条任务，各自落到对应节点、派给对应的人
  • 评论带整改要求，责任人打开任务就知道要做什么
  • 台账回写「已派工」，下次跑不会重复派

跨表对账：流程进度和台账对得上吗

流程走到哪一步、台账记到哪一期，两边应该一致。让 Agent 定期对一遍，不一致的列出来。

点击复制

把「家装业务流程」每条实例当前停在哪一步，和「分期回款台账」里对应合同的最新收款期次对一下。 流程在水电之后但回款还停在首期的、回款到三期但流程还没过瓦木油的，都列出来。 另外，流程里有编号但台账没有的、台账有但流程找不到的，也单独列一份。

  • 两边用合同编号自动匹配
  • 不一致的和对不上号的分开列，方便追责

建表之前，先让它帮您设计字段

表格的字段需要您在界面上建，Agent 负责往里填数据。字段怎么设计，可以先问它。

点击复制

我要做一个「分期回款台账」，应该建哪些字段？给我字段名、类型，单选字段把选项也列出来，我照着建。

  • Agent 会给一张字段表：名称、类型、单选选项
  • 照着在界面上建，五分钟；建完说一声，它就能往里填

📌 建字段时的三个小提醒

单选字段的选项要配全。选项空着的话，Agent 写进去的值会丢，而且不报错。
人员用「文本」类型存姓名，别用「成员」类型——成员列 Agent 填不了。
照片、附件那一列 Agent 也填不了，需要手工上传。其他文本、数字、日期、单选、货币、电话，都能读能写。

📌 关联字段和查询引用：能读，不能建

表与表之间的关联字段、跨表取数的查询引用，建好之后 Agent 读得到值，做汇总分析没问题。但建立关联这个动作需要在界面上做。不想在界面上建关联的话，用合同编号这类业务编号把几张表串起来也一样好用，上面的对账例子就是这么做的。
